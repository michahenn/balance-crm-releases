## Installieren

**Mac:** DMG öffnen, Balance CRM in den Ordner „Programme“ ziehen, starten. Die App ist von Apple geprüft (notarisiert).

**Windows:** Setup ausführen. Falls Windows „Der Computer wurde durch Windows geschützt“ meldet: auf „Weitere Informationen“ → „Trotzdem ausführen“ klicken.

**Update:** Neue Version genauso installieren. Daten und Passwort bleiben erhalten.

## Beim ersten Start

1. Ein Passwort festlegen und gut merken – ohne Passwort lassen sich die Daten nicht öffnen.
2. Bestehende Liste importieren (Excel, CSV, ODS) oder den ersten Kontakt anlegen.
3. Alles Weitere steht im Handbuch in der App (⌘7 bzw. Strg+7).
